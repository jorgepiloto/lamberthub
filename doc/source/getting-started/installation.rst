Installation
############

Install the latest published version from PyPI:

.. code-block:: console

   python -m pip install lamberthub

To install the current development version from GitHub, run:

.. code-block:: console

   python -m pip install \
     https://github.com/jorgepiloto/lamberthub/archive/main.zip

Verify the installation:

.. code-block:: console

   python -c "import lamberthub; print(lamberthub.__version__)"
